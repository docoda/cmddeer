# CmdDeer

**Mac keyboard shortcuts for Windows.** For everyone who switches between a Mac and a Windows PC
and keeps pressing ⌘C, ⌘Z and ⌘W.

CmdDeer runs quietly in the notification area and translates Mac shortcuts into their Windows
equivalents: ⌘C becomes Ctrl+C, ⌘Q becomes Alt+F4, ⌥⇧← selects the previous word.

> **Beta:** CmdDeer is still in development. If something doesn't work, please
> [report it](https://github.com/docoda/cmddeer/issues/new?template=bug_report.yml).

## Features

- 50 Mac shortcuts for editing, files, text navigation, browsers and tabs, each one can be
  turned on or off
- ⌥ Option shortcuts for jumping and selecting word by word
- Conflict check: shows which combinations Windows or other apps already use and asks before
  taking one over
- Cmd on the Windows key (Mac keyboards) or on the left Alt key (PC keyboards)
- A short tap on the Windows key still opens Start; Windows shortcuts you don't remap keep working
- Optional start with Windows, light and dark mode, English and German
- No account, no telemetry, no internet connection. Key presses are never stored or transmitted.
